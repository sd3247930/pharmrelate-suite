籽关通 手机采集端

籽关通（PharmRelate Multi）手机采集端

箱 → 罐 → 粒子 三级包装关联采集 · 离线可用 · 本机生成 XML

这个页面只负责安装。扫码采集、核对、导出都在手机里的 App 内完成， 浏览器页面本身不提供采集功能。

三步上手

  1. 1
    点右上角「📲 安装」
    底部会弹出「📥 下载应用」面板。
  2. 2
    点「📥 下载应用（APK）」
    浏览器直接下载安装包，不会跳到 GitHub 页面。
  3. 3
    装好后从桌面图标打开
    没有地址栏，断网（飞行模式）也能采集。

手机端能做什么

  • 箱号 / 罐号 / 粒子码三条采集通道：扫码（条码）、拍照识别（看照片手输）、手动输入
  • 多箱包装结构：1~5 箱，每箱 1~5 罐，每罐最多 2500 粒，单批上限 12500
  • 分层校验与查重：箱号全批唯一、罐号本箱唯一、粒子码全批唯一
  • 本机生成 XML 并可导出 HTML，与主控机逐字节同源
  • 离线可用：连不上主控机照样采集，事后在本机核对

先看清这三件事

  • 数据在手机上。换机、卸载、清数据前，请先在 App 的「状态 / 导出」里把数据导出保存。
  • 要开两个权限。摄像头（扫码 / 拍照）与存储（导出 HTML 文件）；被拒后可在系统设置里重新打开。
  • 版本可自查。安装面板里给出文件大小与 SHA256，可与你下载到的文件核对。

为什么要装 APK（浏览器里直接用不行吗）

浏览器里只能用键盘手输，调不起摄像头扫码，导出文件也会被浏览器限制。 装上 APK 之后：桌面有独立图标、打开没有地址栏、断网可用、扫码与导出都走本机， 已经装成独立应用时，本页不会再显示「📲 安装」按钮。

安装被手机拦截 / 点了没反应怎么办

被 MagicOS、MIUI、ColorOS 等拦截：按提示允许「安装未知应用」，再选「继续安装」。

在微信 / QQ / 钉钉里点下载没反应：点右上角「···」→「在浏览器打开」， 再点本页右上角「📲 安装」重试。UC、夸克等浏览器若弹「不支持下载」，同样切到系统浏览器。

实在点不动：长按下面这条地址复制，粘到系统浏览器地址栏打开。

换手机 / 重装前先导出进度

采集数据存在手机本机，不在云端。换机或重装前，先在 App 里导出 （状态页「导出为 .html」，或把批次数据导给主控机），装好新机后再导入， 避免数据随卸载一起消失。

签名说明：本安装包使用固定签名证书。若将来换了证书， 系统会要求先卸载旧版本再安装（卸载会清掉本机数据，请务必先导出）。
